# Vendored Web IDL

These files are copied unmodified from the `@webref/idl` package, version
3.85.0 (https://github.com/w3c/webref, MIT license), which extracts the IDL
fragments of the WHATWG and W3C specifications. The specifications themselves
remain under their own licenses.

Refresh with the package's newer release when the bindings need newer
interfaces; `cargo xtask bindgen` regenerates the bindings from them.
